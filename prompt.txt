在现有 cubemap 骨架上，把它做成一个能在六个面上做无缝过滤、并保证接缝采样一致的采样器。保留 Cube、face_uv、sample、seam_error 的现有名字与签名，
只用 Python 标准库，不得引入第三方依赖，不得改动 data/faces.json。

## 需要完成

1. **坐标**
   - 方向向量到面与 UV 的映射要覆盖全部六面，边界归属规则写进 README。
   - 同一方向在相邻两面采样结果必须一致，接缝误差上界写进 README。
2. **过滤**
   - 面边界附近的过滤要跨面取样本，不能只钳制在本面内。
   - 采样要能返回所用面号与 UV，便于验证跨面。
3. **边界**
   - 朝向恰好落在面角、朝向为 0 向量两种情况都要有确定结果。
4. **输出**
   - 同一方向连采两次结果一致。

## 测试

- 覆盖：六面覆盖、跨面采样一致、面角方向、零向量、两次一致。
- `python -m pytest tests -q` 全部通过。

完成后跑一遍 `python -m cubemap.cli data/faces.json --dir 0.6,0.8,0 --out sample.json`，把面号、UV、相邻面接缝误差、跨面采样次数贴进 README。
