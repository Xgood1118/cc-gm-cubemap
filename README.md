# 立方体贴图接缝与过滤

一个能在六个面上做无缝过滤、并保证接缝采样一致的采样器。仅使用 Python
标准库，不依赖第三方包；`data/faces.json` 不做改动。

## 保留签名

- `Cube(faces)`：六面数据容器，`faces` 为 `{面名: 网格}`，面名固定为
  `px / nx / py / ny / pz / nz`（面号 0..5，见 `cubemap.core.FACE_ORDER`）。
- `face_uv(direction) -> (面名, (u, v))`
- `sample(cube, direction) -> SampleResult`
- `seam_error(cube, direction) -> float`

网格标准形式为 `grid[row][col] = [通道...]`，`row 0` 对应 `v = 0`、
`col 0` 对应 `u = 0`；单纹素面允许简写为 `[[通道...]]`（`faces.json` 即此格式）。

## 自测

```
python -m pytest tests -q
python -m cubemap.cli data/faces.json --dir 0.6,0.8,0 --out sample.json
```

## 坐标映射与边界归属规则

取方向向量 `(x, y, z)` 绝对值最大的分量作为主轴，主轴符号决定正负面。
面内先算归一化坐标 `sc, tc ∈ [-1, 1]`，再线性映射 `u = (sc+1)/2`、
`v = (tc+1)/2`（标准 OpenGL 立方体贴图约定）：

| 面号 | 面 | 主轴 | sc | tc |
|---:|---|---|---|---|
| 0 | px | +x | −z/x | −y/x |
| 1 | nx | −x | z/(−x) | −y/(−x) |
| 2 | py | +y | x/y | z/y |
| 3 | ny | −y | x/(−y) | −z/(−y) |
| 4 | pz | +z | x/z | −y/z |
| 5 | nz | −z | −x/(−z) | −y/(−z) |

**边界归属（确定性规则）：**

1. 两个分量绝对值相等（方向落在面边或面角）时，按固定轴优先级
   **x > y > z** 选主轴，再由符号定正负面。例如 `(1,1,0)` 归属 `px`，
   `(0,1,1)` 归属 `py`，八个面角方向（三分量绝对值相等）恒归属 `px/nx`。
2. 零向量 `(0,0,0)` 无方向，约定归属 **`px` 面中心 `(u,v)=(0.5,0.5)`**，
   过滤时按 `+x` 方向处理，结果确定且可复现。
3. 投影超出 `[-1,1]` 的分量钳制到 `[0,1]` UV。

## 无缝过滤与接缝误差上界

过滤核定义在**三维方向空间**：以单位方向 `d` 为中心，用确定性正交切向量
`t1, t2` 张成切平面，在上面取 3×3 tent 核（权重 `[1,2,1]⊗[1,2,1]/16`），
步长为一个纹素（`1/cols`、`1/rows`；单纹素面取 1）。9 个 tap 各自归一化后
独立经过 `face_uv` 落面并做面内双线性插值——越过面边的 tap 自动落到相邻
面取真实纹素，**不做面内钳制**。

因此同一方向生成的 tap 方向集合与权重完全相同，与中心方向归属哪个面无关：

- **接缝采样一致性误差上界 = 0（算法层面严格一致）**，实测连续数据上从
  5 个相邻面独立过滤同一方向，最大通道差为 `0.0`；浮点层面只可能有机器
  epsilon 量级的舍入差（本实现实测 ≤ `2.3e-16`）。
- `seam_error` 度量的是**存储数据本身**在最近接缝处的纹素不连续度：把方向
  夹到相邻面边上反算三维方向，在两面边部分别双线性采样后取通道最大绝对差，
  归一化 `[0,1]` 数据上界为 `1`，零向量返回 `0`。无缝采样不受该差异影响。

`SampleResult` 同时返回 `face / face_index / uv / value / cross_face_count /
taps`，其中 `cross_face_count` 是落到归属面之外的 tap 数（跨面采样次数），
`taps` 给出每个 tap 的面名、UV、权重，便于直接验证跨面行为。同一方向连续
采样两次结果完全相等（结果对象为 frozen dataclass，无随机或全局状态）。
